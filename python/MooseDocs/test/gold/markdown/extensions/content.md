## Next/Previous (Pagination) {#next-previous-pagination}

\"Next\" and \"Previous\" buttons are designed to be the last element of
a page. However, for the case where more markdown content is added
afterwards, the same margin is enforced below the buttons as are above.
They need to appear as items which are distinct from page\'s main body,
similar to how the breadcrumbs navigation is separated, and so this why
the margins are enforced.

The following buttons were configured to link to those pages which
appear before and after this one on the [main index page](/).
